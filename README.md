# PNG to SVG file converter

Turns a pixel-art PNG into an SVG for your laser cutter.

What it does:

    Each color becomes an engrave layer, and a red cut line goes around the art or follows its
    real outline, holes included. The SVG is in millimeters, and a live preview shows exactly what you'll get.

Why I made it:

    Laser software is made for drawings, not pixel art. Tracing a PNG gives blurry edges, and
    drawing every square by hand takes forever. Here the pixel grid is the source of truth, so the engraving and
    the cut line always match.

Use it:

    To use this, go into Main.java and run the file, it will open a program and in the top left corner click open PNG,
    on the right side, you will see a panel that lets you change all the settings. Finally, in the the top left corner,
    you will see a button that says export as SVG and it will let you export it as a laser cutter file, which you can then cut.
